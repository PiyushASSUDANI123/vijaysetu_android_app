# VijaySetu - Android WebView Application

VijaySetu (विजयसेतु) का ऑफिशियल Android WebView ऐप। यह ऐप फील्ड कार्यकर्ताओं (Booth Agents, Panna Pramukhs, Candidate War Room) के लिए सहज और सुरक्षित मोबाइल अनुभव प्रदान करता है।

---

## मुख्य फीचर्स (Key Features)

1. **फुल-स्क्रीन मोबाइल इंटरफेस**: स्टेटस बार के साथ मैचिंग एमराल्ड थीम (`#059669`)।
2. **स्मार्ट स्वाइप-टू-रिफ्रेश (Pull-to-Refresh)**: पेज रीलोड करने के लिए स्वाइप जेस्चर।
3. **नेविगेशन व बैक-प्रेस सपोर्ट**: एंड्रॉइड बैक बटन दबाने पर वेब हिस्ट्री में पीछे जाएगा, सीधे ऐप बंद नहीं होगा।
4. **नेटिव WhatsApp व कॉलिंग सपोर्ट**: जब कार्यकर्ता ऐप में WhatsApp पर्ची या कॉल बटन पर क्लिक करेंगे, तो यह स्वचालित रूप से WhatsApp या फोन डायलर खोलेगा।
5. **फ़ाइल अपलोड व कैमरा सपोर्ट (`onShowFileChooser`)**: वोटर लिस्ट, पीडीएफ या फोटो अपलोड करने की पूरी सुविधा।
6. **ऑफ़लाइन डिटेक्शन व रीट्राई स्क्रीन**: कमजोर या बंद इंटरनेट होने पर खूबसूरत हिंदी/अंग्रेजी एरर स्क्रीन और 'पुनः प्रयास करें' बटन।

---

## ऐप कैसे चलाएं व बिल्ड करें (How to Run & Build)

1. **Android Studio** खोलें।
2. **Open Project** पर क्लिक करें और `Android_app` फोल्डर को चुनें।
3. Gradle Sync पूरा होने दें।
4. **Run 'app'** (`Shift + F10`) दबाएं या **Build > Generate Signed Bundle / APK** से APK तैयार करें।

## यूआरएल कॉन्फ़िगरेशन (Target URL)

यदि आप लाइव यूआरएल के स्थान पर लोकल या अन्य सर्वर इस्तेमाल करना चाहते हैं, तो:
`app/src/main/res/values/strings.xml` में `default_web_url` बदलें:

```xml
<string name="default_web_url">https://vijaysetu.piyushassudani.in</string>
```
